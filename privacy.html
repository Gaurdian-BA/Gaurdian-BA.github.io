Trading System Backup

Privacy policy

Last updated: 8 October 2026.

Purpose and access

This application is used privately by its operator for trading-system backup and recovery. Its Google Drive permission allows broad access to Drive files. The connection uses file contents, metadata and storage-quota information for backup transfer, integrity verification and recovery. It is not a service offered to other users.

Storage and use

Backup data is stored on the operator's Windows computer and Google Drive account. OAuth credentials and tokens are retained in the local rclone configuration and are not published on this website. Operational records can include file paths, sizes, checksums and transfer results.

Google Drive data is used for backup and recovery, not advertising, sale of personal information or training generalized artificial-intelligence models.

Sharing and retention

The application does not sell Google user data. Transfers use Google services and local tools. Backup copies and recovery records are retained under the operator's backup policy; they are not made publicly available by this website.

Control and security

The operator can revoke access through Google Account permissions, remove local credentials and delete selected backups. Revocation stops future API access but does not automatically delete existing copies. Computer, credential and Drive access must be restricted to authorized people. Checksums help detect changed or incomplete backup files.

Website hosting

These static pages have no sign-in form, analytics or tracking scripts. GitHub Pages may log visitor IP addresses for security under its privacy statement.
